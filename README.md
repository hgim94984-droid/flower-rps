# 오늘의 꽃 가위바위보

라이브 방송에서 **MC가 낼 가위·바위·보를 뽑아 주는** 도구입니다.
시작을 누르면 칸 하나 안에서 가위·바위·보가 슬롯머신처럼 빠르게 넘어가고,
점점 느려지다 멈춥니다. 마지막에 멈춰 있는 것이 MC가 낸 패입니다.

설치할 것도, 인터넷 연결도 필요 없습니다. `index.html` 파일 하나로 전부 동작합니다.

---

## 1. 그냥 써 보기 (가장 쉬움)

`index.html` 을 더블클릭하면 브라우저가 열리고 바로 씁니다.

- **시작** 을 누르면 칸 안에서 가위 → 바위 → 보가 위로 빠르게 넘어갑니다
- 점점 느려지다 멈추면 칸이 살짝 커지고, 아래에 **"MC는 바위!"** 가 뜹니다
- 그 옆에 **"이기려면 보"** 가 함께 나와, 시청자 승패를 바로 읊을 수 있습니다
- 멈추는 순간 그림 **왼쪽 아래에 큰 손 모양 배지**(✌ 가위 / ✊ 바위 / ✋ 보)가 뜹니다. 화면을 작게 보는 사람도 무엇이 나왔는지 바로 압니다
- **다시 돌리기** 를 누르면 다음 판이 바로 시작됩니다
- 화면 아래 **지난 판** 칩에 최근 8판 결과가 남습니다 (창을 닫았다 열어도 유지)

### 키보드

| 키 | 하는 일 |
|---|---|
| `스페이스` 또는 `Enter` | 시작 · 다음 판 |
| `M` | 소리 켜기 / 끄기 |
| `N` | 나이트 모드 켜기 / 끄기 |
| `F` | 전체화면 |
| `R` | 지난 판 기록 지우기 |

손이 키보드에서 떨어지지 않도록 전부 한 손에 닿는 단일 키로만 뒀습니다.

### 나이트 모드

오른쪽 위 **🌙** 를 누르면 밤 화면으로 바뀝니다. 다시 누르면 원래대로 돌아옵니다.
`N` 키로도 됩니다. 고른 값은 저장돼서, 창을 닫았다 열어도 그대로입니다.

밤 화면에서도 **가위·바위·보가 나오는 칸만 밝은 종이색으로 남깁니다.**
어두운 데서 그림 선이 묻히지 않고, 불 켜진 슬롯창처럼 보입니다.

### 돌리는 시간

버튼 아래 **짧게 / 보통** 으로 고릅니다. 고른 값은 저장됩니다.

- **짧게** 약 5.8 ~ 6.3초
- **보통** 약 7.0 ~ 7.5초 (기본값)

가장 빠른 구간에서는 **1초에 24칸**이 넘어갑니다.
빠르게 도는 구간이 2초 남짓, 그 뒤 **4초에 걸쳐 천천히 느려지며** 멈춥니다.

멈출 듯하다 **한 칸 더** 넘어가는 밀당이 절반 확률로 붙습니다. 이 한 칸은
시작할 때 이미 계산에 들어가 있어서, 밀당이 있든 없든 결과 확률은 똑같습니다.

---

## 2. 결과는 공정한가요

**공정합니다.** 세 패가 각각 정확히 3분의 1 확률입니다.

- 결과는 **시작 버튼을 누른 그 순간** 브라우저의 암호학적 난수로 먼저 정해집니다
- 그다음 "그 칸에 도착하도록" 불이 도는 횟수를 거꾸로 계산합니다
- 그래서 연출이 끊기거나 느려져도 결과는 바뀌지 않습니다

직접 확인해 보려면 브라우저에서 `F12` → `Console` 탭에 아래를 입력하세요.

```js
__fairness(30000)
```

3만 번 돌린 분포가 출력됩니다. 만든 뒤 실측한 값은 다음과 같습니다.

```
가위 33.29%  바위 33.28%  보 33.43%   (착지 불일치 0건)
```

연출 길이를 재 보려면 `__durations()` 를 입력하세요.

## 3. 방송에 쓸 때

- **창 캡처** 로 잡으면 됩니다. 배경은 자매 게임과 같은 수채화 종이 톤이라 자막·로고와 잘 섞입니다
- 화면이 클수록 글자와 아이콘이 함께 커집니다. 따로 배율을 맞출 필요가 없습니다
- 회전 중에는 **배경 음악 없이 똑딱 소리만** 납니다. MC 멘트와 겹치지 않게 일부러 뺐습니다
- 패마다 똑딱 소리의 음높이가 다릅니다(가위 높음 · 바위 낮음 · 보 가장 높음).
  화면을 안 보고 멘트를 해도 지금 무엇이 지나가는지 귀로 압니다
- 화면이 세로로 짧은 노트북에서도 결과와 지난 판 기록까지 **스크롤 없이** 한 화면에 들어옵니다
- 소리는 **처음 클릭하거나 키를 누른 뒤** 부터 납니다. 브라우저 정책이라 피할 수 없습니다

## 4. 인터넷에 올리기 (선택)

같은 폴더의 `deploy.ps1` 을 쓰면 GitHub Pages 에 올라갑니다.
**처음 한 번만** 아래를 터미널에서 실행해 저장소를 만드세요.

```powershell
gh repo create flower-rps --public --source=. --remote=origin --push
```

그다음 GitHub 저장소 화면에서 `Settings` → `Pages` → `Source` 를 `main / (root)` 로 지정합니다.
이후에는 내용을 고친 뒤 터미널에서 아래만 입력하면 됩니다.

```powershell
.\deploy.ps1
```

1~2분 뒤 `https://hgim94984-droid.github.io/flower-rps/` 에 반영됩니다.

## 6. 가위·바위·보 그림

**오늘의 꽃 캐릭터 그림**을 **자르지 않고 통째로** 씁니다.
칸이 정사각형이라 그림 비율과 딱 맞아서, 어디도 잘리지 않습니다.

| | 파일 | 내용 |
|---|---|---|
| 가위 | `char-gawi.jpg` · `char-gawi2.jpg` | 폭포 정원 / 노란 꽃 그네 |
| 바위 | `char-bawi.jpg` · `char-bawi2.jpg` | 한옥 정원 / 태극 연과 국화 |
| 보 | `char-bo.jpg` · `char-bo2.jpg` | 연꽃 위 / 한옥 연못과 고양이 |

패마다 그림이 **두 장**이고, 돌아갈 때 여섯 장이 차례로 지나갑니다.
같은 패가 나와도 어느 그림이 걸릴지는 그때그때 다릅니다(확률은 패마다 3분의 1 그대로).

그림마다 오른쪽 위에 `가위` / `주먹` / `보` 배지가 들어 있어서,
따로 글자를 덧붙이지 않았습니다.

원본 1254×1254 를 900×900 으로만 줄였습니다(한 장 170KB 안팎).
그림 칸은 **화면 높이에서 버튼·결과 줄을 뺀 나머지를 전부** 차지합니다.
화면이 클수록 그림도 커집니다(1920×1080 에서 약 460px, 최대 600px).
**다운로드 폴더의 원본은 건드리지 않았습니다.**

### 그림을 바꾸고 싶으면

같은 파일 이름으로 덮어쓰기만 하면 됩니다. **정사각형 그림**이면 어떤 크기든 맞습니다.
